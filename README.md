# Personal TradingView — engine v3.9.2

چارت شخصی، همیشه آنلاین، با ناوبری آزاد مثل TradingView و موتور اندیکاتور ۴۴تایی.

🌐 **لینک:** https://rezawin8410-ux.github.io/my-tradingview/
📦 **مخزن:** https://github.com/rezawin8410-ux/my-tradingview

> **نسخه را از عنوان تب چک کن:** `TradingView · vX.Y.Z`.
> گیت‌هاب پیجز `cache-control: max-age=600` می‌فرستد، پس ممکن است تا ~۱۰ دقیقه
> نسخهٔ کهنه سرو شود. اگر عدد قدیمی بود، `?x=1` به آدرس اضافه کن.

| کشیدن / نازک‌کردن کندل‌ها | اسلایدر `#zoomSlider` · دکمه‌های － ＋ · اسکرول ماوس · pinch · کلیدهای `+` و `-` |
| حرکت محور قیمت | درگ **نوار سمت راست** (۵۸px) |
| زوم محور قیمت | اسکرول روی همان نوار — لنگردار: قیمت زیر نشانگر ثابت می‌ماند |
| بازگشت به پیش‌فرض | دابل‌کلیک · دکمهٔ ⟲ · کلید `0` (هر دو محور + زمان) |
| نمایش کل تاریخچه | دکمهٔ `⇔ fit` |
| مخفی‌سازی رابط | `Hide UI` یا `Alt+H` · لایه‌های جدا: `Alt+L` راهنما، `Alt+N` نام‌ها، `Alt+U` نوار وضعیت، `Alt+T` ابزارها |

برچسب `price: auto` / `price: manual` / `osc: manual` همیشه می‌گوید محور دست‌کاری‌شده یا نه.

مقیاس طلا هرگز روی بیت‌کوین نقاشی نمی‌شود.

مسدود از این شبکه و امتحان نمی‌شوند: Binance `451`، Bybit / OKX / Coinbase / Kraken / Stooq / metals.dev `403`.

## اندیکاتورها (۴۴ تا)

- **قیمت (۲۰):** SMA، EMA، WMA، Hull، DEMA، TEMA، VWMA، ALMA، Parabolic SAR (نقطه‌ای)، Bollinger، Keltner، Donchian، S/R Pivots، Auto Fib، Session O/H/L، Candlestick Patterns، SuperTrend، VWAP، **B2 (VP Edge + DeMarker gate)**، فرمول سفارشی
- **اسیلاتور (۱۸):** RSI، StochRSI، Stochastic، MACD، DeMarker، **DeMarker Pro (سه تایم‌فریم + ۴ نوع واگرایی + همگرایی)**، Williams %R، CCI، MFI، ROC، Momentum، ADX/+DI/−DI، Awesome، CMO، Ultimate، TSI، Coppock، Fisher
- **حجم (۶):** Volume، OBV، A/D، Chaikin Money Flow، NVI، Volume Oscillator

## فرمول سفارشی

دکمهٔ `</> Formula`:

- بار جاری: `close` `high` `low` `open` `volume` `hl2` `atr`
- تاریخچه: `close[1]`، `high[3]`
- توابع روی کل سری با `$`: `ema($close,21)` · `sma` · `rsi` · `stdev` · `hh` · `ll` · `shift`
- تبدیل سری به اسکالر هر بار: `at()` — مثلاً `close > at(ema($close,50)) ? 1 : 0`
- خطای نوعی (مثل `rsi($close,14) > 70` بدون `at()`) **اجرا نمی‌شود** و پیام راهنما می‌دهد؛ خط تخت دروغین نقاشی نمی‌شود.

## تست

`/tmp/gate.js` — **۴۲۹ بررسی** روی همان فایل مستقرشده، در `node` (boot خاموش، fetch استاب‌شده، `AbortController` واقعی).
دروازهٔ `deploy.py` تا همه پاس نشوند چیزی پوش نمی‌کند، و شمارهٔ نسخه را در `index.html`
(`app.js?v=…`) همگام می‌کند تا کشِ مرورگر نسخهٔ کهنه سرو نکند. یکپارچگی بایت‌به‌بایت
فایل‌های `.pine` با md5 سورس اصلی بررسی می‌شود.

## محدودیت‌های صادقانه

1. **Pine Script اینجا اجرا نمی‌شود.** اجرای واقعی Pine در مرورگر فقط با `PineTS`
   (AGPL؛ برای محصول بسته $۱,۱۹۹ به‌ازای هر دولوپر) ممکن است. منطق B2 و DeMarker Pro
   در JS بازنویسی شده و سورس پاین بایت‌به‌بایت کنار پروژه است.
2. **`XAU/USD` فقط `1D`.** هیچ API رایگان و CORS-باز تیک اینترادی فارکس نمی‌دهد؛
   ساختن `1m` از بستهٔ روزانه یعنی دادهٔ جعلی. دکمه‌های اینترادی غیرفعال‌اند و پیکر
   راهنمایی می‌کند برای طلای اینترادی از PAXG/XAUT استفاده کنی.
3. **`XAU/USD` حجم ندارد** (هیچ‌یک از دو منبع). پنل Volume و ۷ اندیکاتور حجمی صریحاً
   با پیام «no volume feed» کنار می‌روند، نه با خط صفر.
4. **OHLC روزانهٔ فارکس استنتاجی است:** `open` = بستهٔ دیروز، `high/low` = کران دو بسته.
   در بج با `(ticks)` و در پیکر با `OHLC inferred` اعلام می‌شود.
5. **B2 روی `1h` و `1D` پروفایل نمی‌کشد** چون پنجرهٔ ۲۴ ساعتهٔ پاین آنجا ۲۴ و ۱ بار
   می‌شود و خود پاین با `win < 30` سرکوب می‌کند. دلیلش روی چیپ نوشته می‌شود.
6. **عمق تاریخچه:** گیت‌ایو سقف ۱۰۰۰ بار (≈۱۶ ساعت روی `1m`)؛ آرشیو فارکس تا ۲۰۲۵‑۰۱.
7. **حجم گیت‌ایو اسپات آن جفت است**، نه قرارداد فیوچرز.
8. **market flat ≠ مرده:** اگر بازار ساکن باشد بست تکان نمی‌خورد ولی `poll #N` در HUD
   جلو می‌رود — این دو را از هم جدا می‌کند.
