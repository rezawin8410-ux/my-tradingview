# Personal TradingView — engine v3

چارت شخصی با دادهٔ واقعی، موتور اندیکاتور چندنفره و ویرایشگر فرمول درون‌مرورگری.

🌐 **لینک:** https://rezawin8410-ux.github.io/my-tradingview/

## معماری (چون نسخه‌های قبل باگ داشت)

| لایه | پیاده‌سازی | دلیل |
|---|---|---|
| داده | CoinGecko `market_chart` + کش `localStorage` (TTL ۴۵ ثانیه) | تنها منبع عمومی است که هم `200` می‌دهد هم `Access-Control-Allow-Origin: *` دارد. Binance/Bybit/OKX/Coinbase از این شبکه `451`/`403` برمی‌گردانند. |
| محاسبه | `recompute()` فقط با تغییر داده/پارامتر | در v2 هر `mousemove` کل DeMarker + Volume Profile را دوباره حساب می‌کرد (۲۰ms در هر فراخوانی → لگ). |
| رندر | دو کرباس جدا: `baseCanvas` (کندل/اندیکاتور) + `ovCanvas` (کراس‌هیر) | حرکت موس دیگر هرگز چارت را بازنگرافی نمی‌کند. |
| اندیکاتورها | رجیستری `DEFS` + نمونه‌های فعال (`state.active[]`) | قبلاً فقط B2 به‌صورت هاردکد بود؛ حالا افزودن/حذف/تنظیم هرکدام جداگانه ممکن است. |

## قابلیت‌ها

- **ابزارها:** GOLD (PAXG و XAUT)، BTC، ETH، SOL، XRP، BNB، DOGE، ADA
- **تایم‌فریم:** `5m` `15m` `30m` `1h` `4h` `1D`
  - `5m/15m/30m` از تیک‌های ۵ دقیقه‌ای (۲۴ ساعت اخیر) ساخته می‌شود
  - `1h/4h/1D` از تیک‌های یک‌ساعته (تا ۹۰ روز) تجمیع می‌شود
  - `1m` عمداً حذف شده: هیچ API رایگانی تیک ۱ دقیقه نمی‌دهد و ساخت آن از دادهٔ ۵ دقیقه‌ای یعنی دادهٔ جعلی.
- **اکشن چارت:** درگ (ماوس/لمس) برای جابجایی، اسکرول و pinch برای زوم، دابل‌کلیک یا دکمهٔ ⟲ برای بازگشت
- **کراس‌هیر:** برچسب قیمت روی محور راست، زمان روی محور پایین، و نمایش O/H/L/C/V کندل زیر نشانگر
- **پنل‌ها:** قیمت + Volume + اسیلاتور (پنل‌ها فقط وقتی ظاهر می‌شوند که اندیکاتور فعالی در آن‌ها باشد)
- **اندیکاتورهای آماده:** SMA، EMA، Bollinger Bands، SuperTrend، VWAP، Volume، RSI، Stochastic، MACD، DeMarker، **B2 (VP Edge + DeMarker gate)**
- **فرمول سفارشی:** دکمهٔ Formula → هر عبارت جاوااسکریپت روی سری‌ها بنویس و Plot کن.
  مثلاً `ema(close,21)` یا `(close - shift(close,1)) / shift(close,1) * 100`
- **تنظیمات هر اندیکاتور:** روی چیپِ آن (یا ⚙) کلیک کن؛ پارامترها زنده اعمال می‌شوند.
  ارقام فارسی (`۷`، `۰٫۸`) هم پذیرفته می‌شود.
- **ماندگاری:** نماد، تایم‌فریم، زوم و لیست اندیکاتورهای فعال در `localStorage` ذخیره می‌شود.
- **نشانگر منبع داده:** `LIVE` / `CACHED` / `SIMULATED` — هرگز دادهٔ جعلی را به‌جای واقعی بدون اعلام نشان نمی‌دهد.

## فایل‌ها

```
index.html        رابط و استایل (بدون Tailwind CDN — حذف یک نقطه شکست)
app.js            موتور: TA helpers، رجیستری اندیکاتور، داده، رندر، تعامل
B2_indicator.pine سورس پاین اندیکاتور B2 (برای TradingView / Vela)
B2_strategy.pine  سورس پاین استراتژی B2 با بک‌تست
```

## محدودیت‌های صادقانه

1. **Pine Script اینجا اجرا نمی‌شود.** اجرای واقعی Pine در مرورگر فقط با موتور `PineTS` (مجوز AGPL، و برای بسته‌شده $۱,۱۹۹ به‌ازای هر دولوپر) ممکن است. این پروژه منطق B2 را مستقیماً در JS بازنویسی کرده تا نتیجهٔ یکسان بدهد، و سورس پاین را به‌عنوان مرجع در پنل Formula نگه می‌دارد.
2. **OHLC از تیک ساخته شده، نه از کندل صرافی.** CoinGecko فقط قیمت لحظه‌ای می‌دهد؛ پس `open/high/low/close` از تفاضل نقاط متوالی derive می‌شود. برای سطوح Volume Profile و سیگنال‌های B2 قابل قبول است، ولی با تیک‌های واقعی صرافی یکی نیست.
3. **Volume از `total_volumes` کوینگکو است**، نه حجم واقعی قرارداد فیوچرز.
4. **محدودیت نرخ:** پلن رایگان حدود ۵–۱۵ درخواست در دقیقه است. کش + رفرش ۶۰ ثانیه‌ای برای این گذاشته شده. اگر `429` بخوری، به آخرین کش برمی‌گردد و بج `CACHED` می‌خورد.
5. اگر شبکه‌ات کوینگکو را بلاک کند، چارت با دادهٔ شبیه‌ساز بالا می‌آید و بج `SIMULATED` قرمز آن را صریح می‌گوید.
