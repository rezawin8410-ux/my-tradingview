# Personal TradingView — engine v3.1

چارت شخصی، همیشه آنلاین، با کندل واقعی صرافی و موتور اندیکاتور چندتایی.

🌐 **لینک:** https://rezawin8410-ux.github.io/my-tradingview/
📦 **مخزن:** https://github.com/rezawin8410-ux/my-tradingview

## معماری

| لایه | پیاده‌سازی | چرا |
|---|---|---|
| داده (اصلی) | **Gate.io** `GET /api/v4/spot/candlesticks` · ۱۰۰۰ کندل · `Access-Control-Allow-Origin: *` | کندل OHLCV واقعی از خود صرافی. هر ۸ تایم‌فریم `1m`…`1D` باز و تأییدشده. |
| داده (رزرو) | **CoinGecko** `market_chart` + کش `localStorage` (TTL ۴۵ ثانیه) | فقط تیک قیمت می‌دهد، نه کندل. سقف رزولوشنش ۵ دقیقه است، پس برای `1m`/`3m` اصلاً فراخوانی نمی‌شود (`supports()` ردش می‌کند). |
| مسابقهٔ درخواست | `AbortController` + شمارندهٔ نسل (`loadGen`) | پاسخ کهنه هیچ‌وقت روی دادهٔ تازه نمی‌نشیند (باگی که v3.0 را گرفت). |
| محاسبه | `recompute()` فقط با تغییر داده/پارامتر | در v2 هر `mousemove` کل DeMarker + Volume Profile را دوباره حساب می‌کرد (۲۰ms هر فراخوانی → لگ). |
| رندر | دو کرباس جدا: `baseCanvas` (کندل/اندیکاتور) + `ovCanvas` (کراس‌هیر) | حرکت موس دیگر هرگز چارت را بازنگرافی نمی‌کند. |
| زمان‌بندی | `setTimeout(…,0)` و `requestAnimationFrame` هر دو | در WebView بعضی وقت‌ها RAF تا اولین paint شلیک نمی‌شود؛ مسیر سریع RAF است، مسیر قطعی تایمر. |
| اندیکاتورها | رجیستری `DEFS` + نمونه‌های فعال `state.active[]` | قبلاً فقط B2 هاردکد بود؛ حالا افزودن/حذف/تنظیم هرکدام مستقل است. |
| هندسهٔ کندل | `sanitize()` + `parseGateRows()` | هر بار که `low > min(o,c)` یا `high < max(o,c)` یا زمان تکراری باشد، حذف می‌شود؛ پس هرگز کندل وارونه نقاشی نمی‌شود. |

منابعی که از این شبکه مسدودند و عمداً امتحان نمی‌شوند: Binance `451` (ژئوبلاک)، Bybit / OKX / Coinbase / Kraken `403`.

## قابلیت‌ها

- **ابزارها:** GOLD (PAXG و XAUT)، BTC، ETH، SOL، XRP، BNB، DOGE، ADA — همه روی USDT
- **تایم‌فریم:** `1m` `3m` `5m` `15m` `30m` `1h` `4h` `1D`
  - `1m`≈۱۶ ساعت، `5m`≈۳٫۵ روز، `1h`≈۴۲ روز، `1D`≈۶۱۷ روز (≈۱.۷ سال) تاریخچه
- **اکشن چارت:** درگ (ماوس/لمس) جابجایی · اسکرول و pinch زوم · دابل‌کلیک یا دکمهٔ ⟲ بازگشت به تازه‌ترین
- **کراس‌هیر:** برچسب قیمت روی محور راست، زمان روی محور پایین، و نمایش O/H/L/C/V + تغییر درصدی کندل زیر نشانگر
- **پنل‌ها:** قیمت + Volume + اسیلاتور — پنل‌ها فقط وقتی ظاهر می‌شوند که اندیکاتور فعالی در آن‌ها باشد
- **اندیکاتورهای آماده:** SMA، EMA، Bollinger Bands، SuperTrend، VWAP، Volume، RSI، Stochastic، MACD، DeMarker، **B2 (VP Edge + DeMarker gate)**
- **فرمول سفارشی:** دکمهٔ `</> Formula` → عبارت بنویس و `plot it` بزن. سینتکس:
  - بار جاری: `close` `high` `low` `open` `volume` `hl2` `atr`
  - تاریخچه: `close[1]`، `high[3]`
  - توابع روی کل سری با `$`: `ema($close,21)` · `sma($close,14)` · `rsi($close,14)` · `stdev($close,20)` · `hh($high,14)` · `ll($low,14)` · `shift($close,1)`
  - تبدیل سری به اسکالر هر بار: `at(ema($close,21))` — مثلاً `close > at(ema($close,50)) ? 1 : 0`
  - اگر فرمول خطای نوعی بدهد (مثلاً `rsi($close,14) > 70` بدون `at()`) **اجرا نمی‌شود** و پیام راهنما می‌دهد؛ چارت خط تخت دروغین نقاشی نمی‌کند.
- **تنظیمات هر اندیکاتور:** روی چیپش (یا ⚙) کلیک کن؛ پارامترها زنده اعمال می‌شوند. ارقام فارسی (`۷`، `۰٫۸`) هم پذیرفته می‌شود.
- **ماندگاری:** نماد، تایم‌فریم، زوم و لیست اندیکاتورهای فعال در `localStorage`
- **صداقت منبع داده:** بجِ `LIVE · Gate.io` / `CACHED` / `STALE · Gate.io` / `SIMULATED` — دادهٔ جعلی هرگز جای واقعی بدون اعلام نشان داده نمی‌شود.

## تست

مجموعهٔ واحد در `node` اجرا می‌شود (boot خاموش، `fetch` استاب‌شده، `AbortController` واقعی):
۵۹ بررسی — هر ۱۲ اندیکاتور، نقشهٔ فیلد گیت‌ایو (با آزمون تداوم نسبی، نه آستانهٔ مطلق)،
`sanitize`، `aggregate`، ماتریس `supports()` پرووایدرها، موتور فرمول، و سه سناریوی مسابقهٔ زمانی.
دروازهٔ استقرار (`deploy.py`) تا همه پاس نشوند، چیزی پوش نمی‌کند و شمارهٔ نسخه را در
`index.html` (`app.js?v=…`) همگام می‌کند تا کشِ مرورگر نسخهٔ کهنه سرو نکند.

## محدودیت‌های صادقانه

1. **Pine Script اینجا اجرا نمی‌شود.** اجرای واقعی Pine در مرورگر فقط با موتور `PineTS`
   (مجوز AGPL؛ برای محصول بسته $۱,۱۹۹ به‌ازای هر دولوپر) ممکن است. این پروژه منطق B2 را
   در JS بازنویسی کرده و سورس پاین را کنارش نگه می‌دارد.
2. **پنجرهٔ Volume Profile در B2 بر حسب «بار» است، نه «ساعت».** اسکریپت پاین اصلی
   `winH1 = 24h` و `winH2 = 4h` دارد، ولی اینجا `lookback = 120` بار است. روی `5m` یعنی ۱۰ ساعت،
   روی `1D` یعنی ۱۲۰ روز. **نتیجهٔ بک‌تست پاین با این تنظیم دقیقاً یکی نیست** و این هنوز
   هم‌تراز نشده.
3. **عمق تاریخچه محدود به ۱۰۰۰ بار است** (سقف API رایگان گیت‌ایو). برای `1m` یعنی ~۱۶ ساعت.
4. **محدودیت نرخ:** کش ۴۵ ثانیه‌ای + رفرش ۶۰ ثانیه‌ای برای این گذاشته شده. اگر هر دو پرووایدر
   بخورند، به کش کهنه می‌رود و بج `STALE` می‌خورد — نه دادهٔ ساخته‌شده.
5. **حجم، حجم اسپات آن جفت است**، نه حجم قرارداد فیوچرز.
